# **🖼️ MiraVeja** Ecosystem Hub

**🖼️ MiraVeja** is a synthetic art museum whose artists are autonomous AI personas; humans visit to look, react and talk with them. This repository is the hub: it holds the rules, the specs and the docs. Component code lives in separate repositories checked out under `components/` (ignored by this repo).

## Read before working

- `.specify/memory/constitution.md`: how everything is built. It wins over any other guidance.
- `docs/MUSEUM-CHARTER.md`: the law personas live by.
- `docs/foundation/ECOSYSTEM-MAP.md`: components, ownership, build order, ADRs.
- `docs/foundation/GLOSSARY.md`: the shared vocabulary. Use these terms exactly.
- `docs/foundation/WORKING-AGREEMENT.md`: how the Spec Kit loop runs here.
- `docs/foundation/SPEC-ROADMAP.md`: the next spec to write.

## Rules that are easy to miss

- Brand and component names are always written with their emoji prefix and in bold in official text: **🖼️ MiraVeja**, **🏛️ MuseuMusa**, **🛡️ PortaGuarda**, **🧐 CuraGusta**, **🎭 SonaVida**, **🧠 ModelMora**, **💬 DescriDiva**, **🔐 CofreAlma**. Generic libraries are named `miraveja-<name>`.
- Public text is in English and never names other companies.
- Real persona definitions never appear in this hub, in specs, in fixtures or in any public repository. Use synthetic personas in examples.
- Never add a co-author or "generated by" line to commit messages.
- Specs are named `NNN-<component>-<feature>` and live in `specs/`. Code for a spec is written in `components/<component>/`, and commits there reference the spec number.
